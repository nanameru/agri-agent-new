# プロジェクト要件定義書：営農アシスタント

## 1. プロジェクト概要

### 1.1. プロジェクト名
営農アシスタント (AGRI-Agent)

### 1.2. 目的
地方農業が抱える「深刻な人手不足」と「収益性の低さ」という2大課題を、専門特化AIエージェント群の活用によって解決する。

### 1.3. コンセプト
「IT副業×スマート農業」をテーマに、地方農業と都市部のIT人材をつなぐ新しい働き方を創出し、農業の持続可能性と地方創生を実現する。

### 1.4. 目標成果
- **収益向上:** +190万円/年
- **時間創出:** 事務作業を180時間削減
- **品質向上:** 農産物の糖度を+12%向上
- **持続的発展:** 若手就農者と移住者を増加させ、地域コミュニティを活性化する

---

## 2. 背景と課題

### 2.1. 社会的背景
- **農業従事者の高齢化:** 基幹的農業従事者の平均年齢は68.7歳で、約6割が70歳以上。20年後には担い手が半減するとの予測もある。
- **低い食料自給率:** 農業人口の減少に伴い、食料自給率38%という低水準が続いている。
- **地方移住への関心増:** 35.1%の人が地方移住に関心を持っており、テクノロジーを活用した新しい農業の形が求められている。

### 2.2. 農業経営の3大課題
1.  **煩雑な事務作業:**
    - 年間作付計画、補助金申請、販売資料作成などの事務作業が年間労働時間の18%を占め、本来の生産活動を圧迫している。
2.  **品質管理の難化:**
    - 気候変動の影響により、最適な水やりや施肥のタイミングを見極めることが難しく、品質のばらつきが生じている。
3.  **収益性の低さ:**
    - 多くの農家が卸売市場に依存しているため価格決定力が弱く、中間マージン（約15%）によって収益が圧迫されやすい構造にある。

### 2.3. 課題解決の方向性
「事務作業の自動化」と「データに基づく品質向上」を通じて、農家の収益性を改善することが急務である。

---

## 3. ソリューション概要

### 3.1. ビジョン
**「作業データ入力 → 計画 → 販路開拓」のサイクルをAIで完全に自動化し、地域を活性化する。**

農家は「日報」と「品目データ」といったシンプルな情報を入力するだけで、AIが自律的に最適な経営判断を実行し、成果を最大化する。

### 3.2. システム全体像
6つの専門分野に特化したAIエージェントが連携して動作する「営農アシスタント」システムを構築する。各エージェントは、農家からの最小限の入力をトリガーに、自律的に連携して農業経営全体を最適化する。

---

## 4. 機能要件

### 4.1. ユーザー入力
- 日報の登録
- 品目データの入力
- 作業内容の記録

### 4.2. 6クラスターの専門AIエージェント詳細

#### ① 農業データリサーチ
- **エージェント:**
    - **補助金ウォッチャー:** 全国の補助金・助成金情報を常時監視し、利用可能な制度を自動で推薦・通知する。自動マッチングで最適な補助金を発見し、申請締切日を自動で通知する。
- **ダッシュボード例:**
    - 「スマート農業導入支援事業」適合度:95% (IoTセンサー導入費用の最大1/2を補助)

#### ② 生産管理・計画
- **エージェント:**
    - **作付プランナー:** 土壌データ、気象予測、市場価格を分析し、最適な作付計画と輪作体系を立案する。
    - **水肥最適化ボット:** センサーデータと生育画像から、品質を最大化する水・肥料の最適なタイミングと量を提示する。
- **ダッシュボード例:**
    - トマト圃場へ「明日9:00に15分間の灌水を行うことで、糖度が12%向上する見込みです」とリコメンド。
    - **効果:** 平均糖度12%向上、水使用量30%削減。

#### ③ 申請・手続クラスター
- **エージェント:**
    - **農地取得ナビ:** 農地取得や賃借に関する法的手続きや必要書類をナビゲートする。
    - **補助金フォームビルダー:** 推薦された補助金の申請フォームに、営農データを基に必要な事項を自動入力する。

#### ④ 日報・ナレッジクラスター
- **エージェント:**
    - **日報パーサー:** 音声や手書きメモの日報を構造化データに変換し、自動で記録・整理する。
    - **労務シフトオーガナイザー:** 作業計画に基づき、最適な人員配置と労務シフトを自動で作成する。

#### ⑤ 市場・販路拡大クラスター
- **エージェント:**
    - **Agri-Pitch AI:** 作物の特徴や生産者の想いを基に、魅力的なブランドストーリーやEC商品説明文を自動生成する。
    - **直販チャネルマッチャー:** 作物の特性や顧客層に合わせ、最も収益性の高い直販チャネルを推薦する。

#### ⑥ 生活・移住支援クラスター
- **エージェント:**
    - **お試し滞在サーチャー:** 地方移住希望者向けに、短期の短期滞在プログラムや空き家情報を検索・提供する。
    - **生活コストシミュレーター:** 移住後の生活費や営農収支をシミュレーションし、リアルな生活設計を支援する。

## 5. 非機能要件

- **ユーザビリティ:** スマートフォンやタブレットから、誰でも簡単に日々のデータを入力できる直感的なインターフェースを提供する。
- **自律性・自動化:** ユーザーの介入を最小限に抑え、各AIエージェントが自律的に連携し、24時間365日体制で経営を最適化し続けること。
- **拡張性:** 将来的に新しいエージェントを追加したり、連携する外部サービス（気象情報API、ECサイトなど）を容易に拡張できるアーキテクチャであること。

## 6. 定量的効果

### 6.1. 年間作業時間の削減：180時間/年
- **日報入力・集計の自動化:** 110時間/年
- **申請書類の自動生成:** 25時間/年
- **作付・水肥計画の再計算:** 25時間/年
- **労務シフト表の自動作成:** 20時間/年
- (年間52週で換算すると、週あたり約3.5時間の余裕が創出される)

### 6.2. 収益向上効果：+190万円/年
- **農業純益の向上：+110万円/年**
    - 生産性の向上: +50万円
    - 品質プレミアム: +30万円
    - 直販マージン改善: +30万円
- **副業収入の創出：+80万円/年**
    - 事務作業の自動化で創出した時間（例: 100時間）を高単価な副業（例: 8,000円/時）に再投資することで実現。

## 7. 品質向上による経済効果 (+60万円/年)

### 7.1. 品質向上プロセス
センサーデータ収集 → AIによる水肥最適化 → 品質と価格の向上 (+12%)

### 7.2. 経済効果の内訳
- **品質の均一化とブランド価値創出:**
    - 水ストレスの適切管理により、糖度が平均12%向上し、サイズの均一化を実現。
    - Agri-Pitch AIが品質データを活用し、魅力的なブランドストーリーを自動生成。
- **直販による収益向上:**
    - ECサイト等での直販比率を50%に高め、中間マージンを約15%削減。
- **年間収益向上額:**
    - 品質プレミアム(+30万円)と直販マージン改善(+30万円)の合計で、**年間60万円の収益向上**を実現。

## 8. 社会的インパクト

- **時間的余裕の創出:** AIが年間180時間の事務作業を削減し、その時間を地域活動へ再投資可能にする。
- **地域活動の担い手増加:** 創出された時間で地域の祭りやブランドPR活動に新たな人材が参加し、高齢化が進む地域の伝統文化を維持・活性化する。
- **地域経済の活性化:** 農業の収益性向上と地域ブランド確立により、農産物直販で地域内経済循環が拡大する。
- **地方移住の促進:** 「IT副業×スマート農業」という新しい働き方のモデルが、ITスキルを持つ新たな人材を都市部から地方へ呼び込む。

## 9. 実装ロードマップ

- **対象:** 特定地域の協力農家（数十軒）
- **焦点:** 中核機能の検証と改良
- **主要開発:** 水肥最適化ボット、日報パーサー、補助金ウォッチャー
- **アクション:** 現場フィードバックの収集とUI/UX改善

### Phase 2: 2026年 展開フェーズ
- **対象:** 100農家
- **焦点:** 対象地域と品目の拡大
- **主要開発:** Agri-Pitch AI、直販チャネルマッチャー
- **アクション:** 販路拡大支援機能の強化と収益向上効果の実証

### Phase 3: 2028年 全国展開フェーズ
- **対象:** 1,000農家
- **焦点:** JAや地方自治体との連携強化
- **主要開発:** 地域単位での生産・販売最適化機能
- **アクション:** 地域農業全体の競争力向上支援

## 10. 技術基盤

### 10.1. システムアーキテクチャ
AWSのマネージドサービスを活用したサーバーレスアーキテクチャにより、高い拡張性と信頼性を実現する。

### 10.2. データ収集
- **IoTセンサー:** 土壌・気象センサーからリアルタイムデータを収集。
- **ユーザー入力:** 日報や品目情報を音声・テキスト・写真で入力。
- **外部API:** 補助金情報（Grants）、農水省統計などを連携。

### 10.3. クラウドサービス (AWS)
- **デバイス接続管理:** AWS IoT Core
- **サーバーレス処理:** AWS Lambda
- **ワークフロー管理:** AWS Step Functions
- **AI推論エンジン:** Amazon Bedrock (Claude 3)
- **データ格納:** DynamoDB（構造化データ）、Amazon S3（画像・文書）
- **スケジュール実行:** Amazon EventBridge
- **データ可視化:** Amazon QuickSight

### 10.4. 外部連携API
- **通知・リマインダー:** LINE Messaging API
- **販促資料作成:** Canva API
- **プレゼン資料作成:** Google Slides API

### 10.5. 技術的メリット
- **高いスケーラビリティ:** 利用農家数の増加に応じて自動で拡張。
- **迅速な導入:** 既存APIの組み合わせにより、低コストで迅速な構築が可能。
- **安全なデータ管理:** 農家のデータを厳重に保護するセキュアな基盤。
